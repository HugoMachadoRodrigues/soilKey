# The orders of SiBCS 5 (2018)

As `classify_sibcs()$rsg_or_order` names them. A reference label that is
none of these after `.SIBCS_LEGACY_ORDER_MAP` has no class the key can
return, so
[`normalise_febr_sibcs`](https://hugomachadorodrigues.github.io/soilKey/reference/normalise_febr_sibcs.md)
gives `NA` for it.

## Usage

``` r
.SIBCS_ORDERS
```
