# Perfil canonico de Plintossolo (SiBCS 5a ed., Cap 16)

Reusa fixture WRB Plinthosol – horizonte plintico iniciando dentro de 40
cm. The WRB fixture writes its plinthic horizons "Btv" and "Cv", as KST
and FAO do. In the Brazilian notation "v" marks vertic features and
plinthite is "f", which for KST and FAO is frozen soil: a suffix read
one way by one key is read another way by the next. This profile is
classified by the three keys (it is one of the demonstration profiles of
the app), so its horizons carry neither letter ("Bt", "C") and its
plinthite is the measured one.

## Usage

``` r
make_plintossolo_canonical()
```

## Value

A
[`PedonRecord`](https://hugomachadorodrigues.github.io/soilKey/reference/PedonRecord.md)
populated with the canonical horizons and site metadata for this
reference profile.
